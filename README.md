# Aplicando boas práticas no Frontend

- Acesse os slides em [viniciuscampitelli.com/slides-boas-praticas-frontend](https://viniciuscampitelli.com/slides-boas-praticas-frontend)
- Ou localmente:
  - Clone este repositório com o parâmetro `--recursive`:
    ```shell
    git clone --recursive git@github.com/vcampitelli/slides-boas-praticas-frontend.git
    ```
  - Abra o arquivo `docs/index.html` em seu navegador
